# Nature Kigali — Frontend Showcase

A responsive, premium hospitality website concept built with Next.js 14, React, TypeScript, Tailwind CSS and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## What's included

- Responsive landing page with desktop and mobile navigation
- Stay, dining, birding/nature, events, gallery and location sections
- Enquiry modal with arrival/departure/guest fields
- WhatsApp enquiry handoff (frontend-only)
- Restaurant menu PDF link and Google Maps directions link
- Responsive layouts and subtle hover interactions

## Before presenting to the business

1. Replace the sample stock photography with approved Nature Kigali photographs. The current images are visual placeholders and are not represented as photographs of the property.
2. Confirm phone numbers, menu link, event details and all public business information with the owner.
3. Connect the enquiry/booking form to the property's preferred booking engine or a custom backend only after approval.
4. Add approved guest testimonials and any photography/video rights.

## Important

This is a frontend demonstration. It does not check room availability, create reservations, store customer data, process payments, or connect to a hotel management system.
